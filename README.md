# 📝 React Blog Frontend

## 🚀 Project Overview
This is the frontend part of a blog built with React. It supports creating, editing, and viewing articles using Markdown.

## 📌 Key Technologies
- ⚛ **React** – UI library
- 🎨 **MUI (Material-UI)** – component styling
- 📝 **React Hook Form** – form handling
- 📜 **React Markdown** – Markdown support
- 🌐 **React Router** – routing
- 📦 **Redux Toolkit** – global state management
- 🔗 **Axios** – HTTP requests
- 💅 **Sass** – styling

## 📂 Project Structure
```plaintext
📦 react-blog
 ┣ 📂 src
 ┃ ┣ 📂 components   # Reusable components
 ┃ ┣ 📂 pages        # Application pages
 ┃ ┣ 📂 redux        # Redux setup
 ┃ ┣ 📂 styles       # Global styles
 ┃ ┗ 📜 App.js       # Main component
 ┣ 📜 package.json   # Project configuration
 ┗ 📜 README.md      # Project documentation
```

## 🛠 Getting Started
1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the local server:
   ```sh
   npm start
   ```

## 🌟 Features
✅ User authentication & registration<br>
✅ Create & edit blog posts<br>
✅ Markdown support for articles<br>
✅ Light & dark mode (MUI-based)<br>
✅ Form validation
